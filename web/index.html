이번에 찍은 것

아직 찍은 사진이 없습니다.

공유 창에서 “이미지 저장” 또는 “비디오 저장”을 누르면 사진 앱에 들어갑니다.

설정

후면 카메라

“초광각(Ultra Wide)” 카메라를 고르세요. 고장 난 “후면 카메라(Back Camera)”나 “듀얼 광각(Dual Wide)”은 쓰지 마세요.

화질

1×는 초광각 화면을 잘라서 만들기 때문에 화소가 적습니다. 가장 큰 해상도로 받은 뒤, 잘라낸 사진을 고품질로 키우고 선명하게 보정합니다. 디테일이 가장 많이 남는 건 0.5×입니다.

저장

촬영하면 바로 공유 창이 뜹니다. “이미지 저장”/“비디오 저장”을 누르면 사진 앱에 들어갑니다. (iOS는 웹페이지가 사진 앱에 직접 저장하는 것을 허용하지 않아서 이 한 번의 탭은 꼭 필요합니다)

화면 · 소리

도움말

  • 홈 화면에 추가하면 앱처럼 쓸 수 있습니다. (Safari 공유 버튼 → “홈 화면에 추가”)
  • 카메라 권한을 매번 묻지 않게 하려면: 설정 앱 → 앱 → Safari → 카메라(와 마이크) → 허용. 웹페이지는 이 창을 스스로 없앨 수 없어서 iOS 설정에서 바꿔야 합니다.
  • 찍은 사진은 이 웹앱 안에 임시로 보관됩니다. 왼쪽 아래 미리보기를 눌러 사진 앱에 저장하세요.
  • 1×, 2×는 초광각 카메라를 디지털로 확대한 것입니다. 두 손가락으로 확대/축소할 수 있습니다.
  • 가로 사진을 찍으려면 제어 센터에서 화면 세로 고정을 끄세요.
